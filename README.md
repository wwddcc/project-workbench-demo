# 项目管理工作台 · 独立静态演示

基于用户提供的 10 张参考图，以 Vue 3、Ant Design Vue 4 和 Vite 实现。项目独立于 iresp-vue3，不调用后端、不连接数据库。

## 启动

```powershell
cd D:\workspace\iresp\irespboot\project-workbench-demo
npm install
npm run dev
```

访问 http://127.0.0.1:5188/ 。构建使用 `npm run build`，产物在 `dist/`；构建后使用 `npm run preview` 预览。静态服务器可直接托管 `dist/`，路由采用 hash。

当前本机验证复用了相邻 iresp-vue3/node_modules（目录联接），没有修改主项目 package.json 或锁文件。复制到其他机器时不复制 node_modules，按上述命令独立安装。声明版本范围与相邻项目保持兼容；本次实际验证 Vue 3.5.12、Ant Design Vue 4.2.5、Vite 5.4.10。

## 还原范围

- 沿用参考图浅蓝背景、固定侧栏、白色卡片、统计波形、彩色进度条和密集信息布局。
- 主要对照约 600px 宽的参考尺寸，同时提供桌面扩展与窄屏适配。
- 原头像素材不可得，采用示例头像；图标使用 Ant Design Icons，图表以 SVG/CSS 重绘，未复制公众号水印。
- 当前是布局与交互演示，部分下拉仅作外观展示；日期范围不接业务筛选。详情统一使用演示抽屉，不包含真实权限、文件上传、账号认证或第三方服务集成。
- 数据为本地示例，新增、审批和设置在当前会话内有效，刷新恢复初始数据。统计数字按参考图展示，不与所有示例操作联动。
